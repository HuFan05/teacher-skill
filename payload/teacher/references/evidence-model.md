# 证据模型

一个结果的**名称**决定它能支撑多强的结论。升级结论的唯一方式不是把话说得更确定，
而是拿到更高等级的证据。

## 等级

从强到弱。名字固定，不得互换，不得新增。

| 等级 | 含义 | 在 CS/AI 里的实例 |
| --- | --- | --- |
| `formal` | 形式化验证 | 证明助手或模型检查器验证过的正确性/复杂度界；状态空间穷尽验证 |
| `certificate` | 可检查证书 | 机器可验证的反例；一个检查器能验证的证书；可复现的构造 |
| `exact_reproduction` | 精确复现 | 固定数据/环境/种子，逐字节或声明容差内一致 |
| `bounded_empirical` | 有限范围经验证据 | 在声明范围内的数据集/规模/种子/超参区间内成立 |
| `numerical_evidence` | 数值证据 | 损失曲线、指标贴图、数值吻合；只有提示性 |

## 规则

`constants.MINIMUM_GRADE_BY_STRENGTH` 是守卫执行的表格：

| 结论强度 | 允许的最低等级 |
| --- | --- |
| `universal`（全称） | `formal`、`certificate` |
| `conditional`（条件） | `formal`、`certificate` |
| `bounded`（有界） | `formal`、`certificate`、`exact_reproduction`、`bounded_empirical` |
| `observation`（观察） | 任意 |

推论：

- `numerical_evidence` **撑不起**全称、条件或有界结论。它只能支撑一条观察记录。
- 一条有界结论**必须在 `cannot_imply` 里写明它的边界**，否则不成立。
- 任何结论都必须声明适用范围（`datasets` / `models` / `compute` / `seeds` / `assumptions`）。
  没有声明范围就没有可检查的边界。

## 强制写"不能推出什么"

每一条结论都必须写 `cannot_imply`，非空。这是防止有限结果在后续摘要里被放大的主要手段。

在本领域，`cannot_imply` 的典型写法：

- 「在单数据集上有效」不能推出「方法普遍有效」
- 「在小规模上成立」不能推出「在更大规模上成立」
- 「固定种子下复现」不能推出「对随机性稳健」
- 「该配置下指标提升」不能推出「该机制是提升的原因」
- 「环境 A 中可复现」不能推出「环境 B 中可复现」

## 结论的效果是推导的，不是赋值的

一条记录的效果由它的**本地评审**与**依赖闭包**共同决定：

| 效果 | 条件 |
| --- | --- |
| `invalid` | 本地评审为拒绝 |
| `needs_review` | 依赖链未闭合，或本地评审不一致 |
| `current` | 本地评审接受且依赖链闭合 |
| `historical` | 尚未评审 |

**没有任何地方可以直接给效果赋值。** 因此继续工作本身不会把结论升级——
只有一次接受状态的本地评审，加上一条闭合的依赖链，才会。

## 来源与信任

- **外部评审（`foreign`）会被记录，但从不提升本地可信度。** 导入一份别人用 AI 跑出来的结果，
  它仍然需要本地的接受评审。
- 锚点有过期状态。引用了**不存在**的锚点与引用了**已过期**的锚点，是两个不同的风险码，
  分开报告——合并它们会掩盖后者的存在。
- 「工具运行成功」不等于「结论成立」；「结构校验通过」不等于「内容正确」；
  「用户满意」不等于「事实状态升级」。

## 回答里的依据

每条要点除了强度与等级，还要声明**依据**。依据决定它能引用什么证据，也决定界面上怎么标注它：

| 依据 | 必须引用 | 界面标注 | 规则 |
| --- | --- | --- | --- |
| `retrieved_source` | 本轮取得的来源片段 | 来源引用（未复现） | 若给出原文，必须逐字节出现在所引片段里 |
| `executed_check` | 本轮的执行结果 | 本地执行核验 | 程序跑通只核验它检查到的边界；`formal`/`certificate` 只能来自配置里声明为检查器的命令 |
| `user_supplied` | 用户原话中的逐字片段 | 你提供的材料 | 引文逐字节核对 |
| `reasoning` | 不引用证据 | 仅凭推理（未核验） | 不得分级，不得是全称结论；只要有这样的要点，就必须写出未知项 |

“来源引用”是引证式保证：Skill 核对了引文确实在来源里，没有复现来源本身的结论。

## 答案门产出的指标

每个通过的回答都附带一组整数与布尔值，由程序计算，模型无法设定：

- 要点数、有已核验依据的要点数、仅凭推理的要点数；
- 本轮可用的证据片段数、被引用的片段数；引文核验数 / 引文数；
- 调查步数 / 预算、执行的操作数、被拒绝的操作数、看过的候选数、未展示的候选数；
- 预算是否用尽、来源是否不足；可见字符数；
- `semantic_correctness_proven: false`（永远如此）。

答案末尾还会给出：由 Skill 在原位置重新读到的片段数（`verified`）、只能采信宿主 agent 的片段数（`declared`）、
与原位置不符而被丢弃的片段数（`mismatch`）。
